# Processor Showcase

A React-based web application built to display the history, specifications, and architectural evolution of various microprocessors.

*Note: This project is currently in active development. Features and architecture are subject to change.*

## 🛠 Tech Stack

*   **Frontend:** React (Vite)
*   **Styling:** Tailwind CSS
*   **Animations:** Framer Motion

## 🚀 Local Development
